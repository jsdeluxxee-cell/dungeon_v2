# Reflection

It took me 1 spec iteration to get a fully working dungeon. The main issue I ran into was not the AI output, but using the wrong file at first and editing `dungeon.json` instead of `ai_dungeon.json`. Once I corrected that and loaded the proper file, the dungeon ran correctly.

What surprised me most was how the dungeon still felt like an actual game even though I had designed the system and provided the structure for the AI-generated content. I did know roughly what would appear since I wrote the rules and controlled the prompt, but it still felt different seeing the full dungeon laid out and playing through it step by step. I would be fine using AI to generate parts of a game, like dungeon layouts or descriptions, but not as a major core system without review. AI is useful for speeding up content creation, but it still needs a developer to guide and check the output.
